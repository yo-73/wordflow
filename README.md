# WordFlow v4.0 — iPhone向け英単語学習PWA

英検準1級〜1級初歩・難関大学入試・TOEFLを想定した英単語帳です。全1,500項目（英単語1,002／熟語・句動詞457／入試会話表現41）を収録しています。品詞・意味・頻出構文・英文例文・日本語訳つきです。難易度は目安であり、各試験の公式出題語彙との照合を保証するものではありません。

## 使い方

1. **カードをタップ**して答え・品詞・意味・構文・例文を見る。
2. **左スワイプ**で「まだ覚えていない」→自動で復習待ちへ。
3. **右スワイプ**で「覚えた」→正解として記録。
4. 左スワイプしたカードは、それ以降、**2回続けて右スワイプ**すると復習待ちから卒業。間違えるとカウントをやり直します。
5. 右上などに専用の「追加」ボタンは不要。誤答判定がそのまま復習リスト登録になります。

**重要：** v4では答えの表示前に左右へスワイプしても判定されません。先にカードをタップしてください。PCでは答えを表示した後に左右矢印キーでも判定できます。

学習モードはランダム／間違い復習／熟語集中／会話表現／未学習／復習タイミングの6種類。1回10・20・30・50問から選べます。間違い復習はミス回数と復習時期を考慮して優先します。

## 公開してiPhoneで使う（GitHub Pagesの例）

ZIPをダウンロード後、展開して `wordflow` フォルダー内の `index.html`, `app.js`, `cards.json`, `sw.js`, `styles.css`, `manifest.webmanifest`, `icons/` を取り出します。

1. GitHub（https://github.com/）で新しいリポジトリを作ります。GitHub Pages無料利用のため、通常は**公開（Public）リポジトリ**にします。
2. リポジトリのトップ階層に `wordflow` **フォルダーの中身**をアップロードします（`wordflow/wordflow/index.html` のような二重の階層にしない）。
3. リポジトリの **Settings → Pages → Build and deployment** で `Deploy from a branch`、`main`、`/(root)` を選んで保存します。
4. 公開URL（通常 `https://GitHubユーザー名.github.io/リポジトリ名/`）をiPhoneの**Safari**で開きます。Safariの「共有」から**ホーム画面に追加**を選びます。
5. 初回はインターネット接続が必要です。初回表示とキャッシュ登録が済めば、オフライン時は保存済みのアプリ／単語データで学習できます。ただしオフライン動作は端末・ブラウザ側のデータ保持に依存します。

**注意：** アプリのソースと内蔵の1,500語データは公開リポジトリ上で誰でも閲覧可能です。個人の学習履歴・追加単語・復習データは標準ではGitHubへ送信せず、利用端末の `localStorage` に保持します。ブラウザのサイトデータ削除、ホーム画面アプリの削除、端末故障などに備え、**設定 → 全データをバックアップ**から定期的にJSONファイルを書き出してください。

## バージョンアップする場合

1. 旧アプリ内の **設定 → バックアップ**で学習記録を保存します。
2. 同じGitHub Pagesの公開URLに、v4.0の各ファイルを上書きで公開します。
3. Safari／ホーム画面アプリで読み込み直します。更新された単語データが表示されない場合は、インターネット接続時にアプリを完全に閉じて再起動してください。**サイトデータを削除するのは避けてください**。
4. 保存場所（URLのオリジンやiOSでのWebアプリの保存領域）が変わると、履歴が自動引き継ぎされない場合があります。その場合はバックアップを復元します。

以前の1,500項目の見出し語とIDは維持しています。v4では約50項目の辞書内容を補正／補足しており、単語データだけでなくアプリ機能も更新しています。**既存の内容をもう一度インポートしないでください**（上書きになることがあります）。

## PCで試す場合

`wordflow` フォルダーで：

```bash
python3 -m http.server 8000
```

その後PCのブラウザで `http://localhost:8000/` を開きます。`index.html` を直接ダブルクリックして `file://` で開くと、単語データの取得が失敗する場合があります。

## 単語データの追加・編集

- 「単語帳 → ＋単語を追加」で、品詞・意味・構文・例文を入力。
- 「設定 → 単語データを取り込む」でCSV/JSONの一括追加・上書き。
- 既存カードも単語帳で編集できます。
- 全標準データは `cards.json` に格納。
- 追加・編集は自分の端末に保存され、GitHubのソースファイルには反映されません。

## 品質と動作確認の範囲

- 1,500項目について、ID／見出し語重複、必要項目の空欄、品詞表記の構造、英日例文・構文の有無を自動検査。
- 既存1,500項目のID・見出し語の維持を検査。
- `appropriate`, `compromise`, `objective`, `implement`, `elaborate` などの主要な多義語を補正。31カードに追加英文例と和訳を収録。
- 学習ロジックをNode.js実行環境で検証（6種類の出題モード、誤答記録、取り消し、復習卒業、既存履歴、単語のマージ、検索・ページング）。
- **全1,500項目の意味・自然さを辞書と1件ずつ突合したわけではありません。** 人手で確認したのは重点的な多義語・語法・代表的な表現です。
- ブラウザでの自動操作は実行環境の通信制限のため完了できず、**iPhone実機での動作は未確認**です。オフライン機能の実機検証も未完了です。

## 技術構成

HTML/CSS/JavaScriptの静的Webアプリ。外部API・ユーザー登録は不要。PWAのService Workerによりアプリ・カードデータをキャッシュし、ローカル保存により学習記録を保持します。GitHub Pages以外のHTTPSの静的ホスティングでも利用できます。
